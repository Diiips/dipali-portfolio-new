# Dipali Portfolio

## Upload to GitHub
1. Extract this ZIP.
2. Upload the dist folder, vercel.json, and README.md to the root of your new repository.
3. Do not upload the ZIP itself.

## Deploy a new Vercel project
1. In Vercel, choose Add New > Project and import this new repository.
2. Choose a new project name.
3. Framework Preset: Other.
4. Root Directory: leave at repository root.
5. Build Command: empty (no build required).
6. Output Directory: dist.
7. Click Deploy.

vercel.json includes these settings. No npm install or environment variables are required.

Website files are in dist/. Edit index.html for content, style.css for styling, and projects.js for project popup behavior. Keep the three PNG assets with the website files.
